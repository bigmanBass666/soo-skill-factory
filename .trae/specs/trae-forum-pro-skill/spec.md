# TRAE 论坛社区助手 (trae-forum-pro) Spec

## Why

TRAE 官方论坛（forum.trae.cn）是用户获取帮助、反馈建议的核心社区平台，但存在三大痛点：(1) 大量求助帖信息缺失/格式混乱导致回复效率低下；(2) 新用户不熟悉官方帖子规范（产品建议/Bug 反馈/求助帖格式各异）；(3) 社区有价值信息散落各处缺乏系统整理。本 Skill 将"智能搜索 → 规范发帖 → 社区洞察 → 互动管理"全流程封装为可复用能力，与已完成的 `trae-device-security`（账号安全护盾）形成互补 — 一个保护账号安全，一个提升社区效率。同时作为 SOLO 技能创作赛第二件参赛作品。

## What Changes

- 创建全新的 TRAE SOLO Skill 目录结构：
  ```
  trae-forum-pro/
  ├── SKILL.md                    # Skill 核心定义（<500行）
  ├── references/
  │   ├── forum-guide.md          # TRAE 论坛完整使用指南（版块/规则/格式规范）
  │   ├── hot-topics.md           # 热门话题与趋势分析库
  │   └── post-templates.md       # 各类帖子模板库（产品建议/Bug/求助/分享）
  └── scripts/
      └── forum-search.sh         # 论坛搜索与摘要辅助脚本
  ```
- 不修改任何现有代码或已有 Skill，纯新增
- 可选：基于之前论坛研究积累的数据（6+ 关键帖子）构建 references 数据源

## Impact

- 全新 Skill，无破坏性变更
- 依赖：WebFetch 工具（抓取论坛内容）、Playwright MCP（自动发帖）、SearchCodebase/Grep（本地搜索）
- 目标产出：可安装的 `.skill` 文件 + 参赛帖（发布到 #17079 同一赛区）
- 与 `trae-device-security` 的关系：互补定位，无代码依赖

## ADDED Requirements

### Requirement: SKILL.md 核心定义

SKILL.md SHALL 包含以下 frontmatter 和正文：

#### Frontmatter 字段
- `name`: `trae-forum-pro`
- `description`: 触发描述需"pushy"，覆盖关键词：TRAE论坛、发帖、搜帖子、找答案、写建议、Bug反馈、社区动态、帖子格式、论坛搜索、官方回复
- `compatibility`: WebFetch, Playwright MCP, SearchCodebase/Grep

#### 正文结构（Progressive Disclosure 原则）

1. **Skill 概述** — 一句话：TRAE 论坛的智能社区助手，帮你搜答案、写好帖、看趋势
2. **触发场景列表** — 至少 10 个明确触发场景
3. **核心工作流** — 分模块描述四大能力：
   - **模块 A：智能搜索助手** — 结构化论坛搜索与解决方案提取
   - **模块 B：帖子格式化引擎** — 按官方规范生成各类标准化帖子
   - **模块 C：社区趋势分析** — 热门话题识别与社区动态追踪
   - **模块 D：互动管理工具** — 草稿管理/帖子跟踪/回复辅助
4. **输出格式规范** — 定义每类输出的模板
5. **最佳实践** — 论坛礼仪与高效沟通技巧

### Requirement: 模块 A — 智能搜索助手

系统 SHALL 帮助用户在 TRAE 论坛中高效找到所需信息。

- **WHEN** 用户描述问题并要求找答案 → 自动构造搜索策略（关键词提取→论坛板块定位→帖子筛选→内容提取）
- **WHEN** 找到多个相关帖子 → 生成对比摘要表（标题/回复数/核心结论/相关性评分）
- **WHEN** 未找到精确匹配 → 推荐相似话题 + 建议发新帖
- **输出格式**：结构化搜索报告，包含：
  - 匹配帖子列表（按相关性排序）
  - 每个帖子的关键信息提取（问题描述+官方回答+社区方案）
  - 推荐操作路径

### Requirement: 模块 B — 帖子格式化引擎

系统 SHALL 按 TRAE 论坛官方规范自动生成标准化帖子。

#### 支持的帖子类型：

| 类型 | 格式要求 | 发布板块 |
|------|---------|---------|
| 产品建议 | 【产品建议】标题 + 痛点场景 + 影响范围 + 方案(P0/P1/P2) + 预期效果 | 产品建议区 |
| Bug 反馈 | 【Bug 反馈】标题 + 环境信息 + 问题描述 + 复现步骤 + 期望行为 + 截图指引 | Bug 反馈区 |
| 求助提问 | 简明标题 + 运行环境 + 问题描述 + 已尝试方案 + 期望结果 | 帮助与支持 |
| 经验分享 | 【分享】标题 + 背景介绍 + 操作步骤 + 效果展示 + 注意事项 | 综合讨论 |

- **WHEN** 用户说"帮我写一个帖子" → 先询问帖子类型和关键信息 → 按对应模板生成
- **WHEN** 用户提供原始内容 → 自动补全缺失字段（如环境信息、复现步骤）
- **生成的帖子 SHALL 包含**：合适的标签推荐、分类选择建议、标题优化建议
- **用户可编辑**：生成后允许修改再确认

### Requirement: 模块 C — 社区趋势分析

系统 SHALL 帮助用户了解论坛社区动态。

- **WHEN** 用户问"最近论坛上在讨论什么" → 抓取首页/热门列表 → 分析主题分布 → 生成趋势报告
- **WHEN** 用户关注特定话题 → 追踪该话题下的新帖子和回复
- **输出格式**：
  - 热门 TOP10 帖子（标题/热度/趋势方向↑↓）
  - 话题分类统计（功能请求/Bug/使用技巧/讨论/其他）
  - 官方动态标记（含官方回复的帖子特别标注）
  - 新兴话题预警（短时间内爆发的新讨论）

### Requirement: 模块 D — 互动管理工具

系统 SHALL 提供帖子生命周期管理能力。

- **草稿管理**：保存/加载/列出草稿到 `~/.trae/forum-drafts/`
- **帖子跟踪**：记录已发布的帖子 URL，支持后续查看回复状态
- **回复辅助**：基于上下文生成回复建议（引用原帖内容 + 建设性回复模板）
- **失败回退**：发帖失败时保存草稿并提示手动重试

### Requirement: 参考文件 (references/)

系统 SHALL 提供丰富的参考数据：

1. **`references/forum-guide.md`** — TRAE 论坛完整使用指南
   - 版块结构与导航说明
   - 发帖规则与礼仪
   - 帖子类型与格式规范详解
   - 常见问题 FAQ

2. **`references/hot-topics.md`** — 热门话题数据库
   - 基于 forum-data.md（从 device-security 移植）扩展
   - 包含更多帖子的元数据和摘要
   - 分类索引（按话题类型/时间/热度）

3. **`references/post-templates.md`** — 帖子模板库
   - 4 种帖子类型的完整模板（带示例填充）
   - 常用 Markdown 格式技巧（表格/引用/代码块/图片）
   - 标签使用指南

### Requirement: 辅助脚本 (scripts/)

- **`scripts/forum-search.sh`** — 论坛搜索辅助脚本
  - 支持关键词搜索、板块过滤、排序方式
  - 输出结构化搜索结果（JSON + 可读文本双模式）
  - 缓存机制避免重复请求

### Requirement: 测试用例 (Evals)

系统 SHALL 定义至少 3 个测试用例：

| ID | 场景 | Prompt 示例 | 预期输出 |
|----|------|------------|---------|
| 1 | 智能搜索 | "我在用 TRAE 写代码时经常卡死，帮我去论坛找找有没有人遇到同样的问题" | 结构化搜索报告（>=3个相关帖子 + 摘要 + 推荐） |
| 2 | 帖子生成 | "我想反馈一个 Bug：TRAE 的自动保存有时候会丢失我的代码改动" | 符合 Bug 反馈格式的完整帖子文案 |
| 3 | 趋势分析 | "最近 TRAE 论坛上大家最关心什么？帮我整理一下" | 趋势报告（TOP10 + 分类统计 + 官方动态） |

每个 eval 的 expected_output SHALL 定义明确的断言点（assertions），用于 grading。
