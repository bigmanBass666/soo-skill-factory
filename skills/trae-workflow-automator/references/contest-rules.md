## 二、投稿格式要求

### 发布位置

参赛帖发布于 SOLO 技能创作赛专区：
https://forum.trae.cn/c/37-category/37

### 帖子标题格式

```
【技能创作赛】{Skill名称} - {一句话描述}
```

示例：
```
【技能创作赛】API-Doc-Generator - 一键生成RESTful API文档
```

### 内容要求

参赛帖必须包含以下五个部分：

1. **Skill介绍**：清晰描述技能的定位与目标
2. **核心能力**：列出技能的主要功能点
3. **使用场景**：展示技能适用的真实场景
4. **技术亮点**：说明技能在方法论、架构或实现上的创新
5. **安装方式**：提供完整的安装与使用指引

### 附件要求

- 必须附带 `.skill` 文件
- `.skill` 文件采用 `zip` 格式打包
- 打包内容应包含 SKILL.md、references/、scripts/、evals/ 等完整目录结构

## 三、评审标准

| 维度 | 权重 | 说明 |
|------|------|------|
| 创新性 | 25% | Skill概念的独特性和创意，是否提出新颖的解决方案 |
| 实用性 | 25% | 解决真实问题的程度，是否具有广泛的应用场景 |
| 完成度 | 25% | 功能完整性、文档完善度、用户体验的打磨程度 |
| 技术深度 | 25% | 方法论运用是否合理、eval覆盖是否充分、benchmark数据是否支撑结论 |

### 各维度详细说明

**创新性**：是否提出全新技能概念、对现有方案有显著改进、具备独特交互或实现方式

**实用性**：是否解决开发者真实痛点、适用场景广泛、使用门槛合理

**完成度**：核心功能是否完整可用、文档是否清晰易懂、异常处理是否完善

**技术深度**：SKILL.md 方法论描述是否详尽、evals/ 测试用例是否充分、benchmark 数据是否客观可信

## 四、参赛帖模板（七章标准格式）

参赛帖须按照以下七章结构撰写：

### 一、Skill简介

简要介绍技能的定位、解决的问题和核心价值。让读者在30秒内理解这个技能做什么。

### 二、核心能力

以列表形式展示技能的主要功能点，每项能力配以简短说明。

### 三、场景演示

通过2-3个典型使用场景，展示技能在实际开发工作流中的价值。建议配合截图或代码片段。

### 四、Benchmark数据

展示技能的量化评估结果，包括：
- 各 eval 的通过率
- 关键指标的 benchmark 数据
- 与基线方案的对比（如有）

### 五、核心代码展示

摘录技能实现中最关键、最有技术含量的代码片段，并附以简要说明。

### 六、技术亮点

深入阐述技能在以下方面的创新：
- 方法论设计
- 架构选择
- Prompt 工程
- Eval 与 Benchmark 策略

### 七、安装使用

提供完整的安装与使用指引：
- 环境要求
- 安装步骤
- 基本用法示例
- 常见问题解答

## 六、投稿 Checklist

投稿前请逐项确认：

- [ ] SKILL.md 完整且行数 < 500 行
- [ ] references/ 目录包含必要的参考文件
- [ ] scripts/ 目录包含辅助脚本（如有）
- [ ] evals/ 目录包含测试用例（>= 3 个 eval，>= 15 个断言）
- [ ] benchmark 数据已生成
- [ ] .skill 文件已打包为 zip 格式
- [ ] 参赛帖已发布到正确板块（SOLO 技能创作赛专区）
- [ ] 参赛帖标题符合格式要求且内容包含七章标准格式
- [ ] 抽奖问卷已填写
